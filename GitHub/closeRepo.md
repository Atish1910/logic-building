# Git Workflow Steps

## ✅ Step 1: Clone the Repository

```bash
git clone https://github.com/gladowl-ticket/pillai-2026.git

Tip: You can paste in terminal using Shift + Insert

✅ Step 2: Check Current Branch
git branch

✅ Step 3: Create New Branch
git checkout -b atish

✅ Step 4: Verify Branch
git branch
You will see something like:
main
atish

✅ Step 5: Push New Branch to GitHub
git push -u origin atish
```
