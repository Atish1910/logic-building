# What is "any" type in TS:

    - when variable is declared with "any" type then no typechecking and no compile time error.
    - It jsut give any type of data is acceptable.

    let x:any;
    x = 1;            <- Number
    x = "shubh";       <- string
    x = true;          <- boolean
    x();               <- function
    x.property = 10;    <- Object
