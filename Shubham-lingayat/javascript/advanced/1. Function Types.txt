# 1. Name Function:

# 2. Arrow Function:

    - Defined using arrow - no need to declare function keyword.
    - difference is 
        - can not be called as constuctor
        - argumnets keyword not works.
        - this keyword taks data from self arrow functional scope only.
        - no need to return if we don't used brackets. - if we used brackets then need to return the data.
        - Hoisting -> considers it as an varibale. (if we use normal function then it will be get called using hoisting).
    
    const shubhamzz = () => {
        console.log("Heeloo World!);
    }
    shubhamzz();

# Pure and Impure Functions:
    1. Pure Function:
        - Pure function are those functions which gives same output when we give the same input again.

        function add(a,b){
            return a+b;
        }
        console.log(4,2);   // Output --> 6
        console.log(4,2);   // Output --> 6

    2. Impure Function:
        - Impure Function are those functions which gives different output even we give same input again.

        let total = 0;
        function add(num){
            return total += num;
        }

        console.log(5); // Output --> 5
        console.log(5); // Output --> 10

    - here we using closure - nestead function.
    - returned function can take parameters.
    - passing the arguments in nestead function. 
    - If there are complex function and required multiple arguments then we can broken down into small reusable functions with fewer argument.

    function multiplication(a){

    // calling the function

# Call, Apply and Bind methods in JS:
    - these three methods are used with "Functions" and control how they are Invoked.
    - these methods provide a way to manipulate "this" value.

    // function contains "this", but don't have any value need to apply/bind/call this value

    function shubh_01(message){
        console.log(`${message}, ${this.name}!`);
    }

    // varibale which is object
    const name_value = { name:"Shubham" };
    
    1. Call:
        - Invoke the function with specific context and argument.
        example:
            shubh_01.call(name_value, "Hello");

            // Output --> Hello Shubham
    
    2. Apply:
        - Invoke the function with specific context and array of arguments.
        example:
            shubh_01.apply(name_value, ["Hi"]);

            // Output --> Hi Shubham
    
    3. Bind:
        - Bind the specific context. and Invoke later.
        - It doesn't invoked immediately.
        
        const new_01 = shubh_01.bind(name_value);
        new_01("Hii");

# Smmary:
    1. call -> invoked with specific context and arguments.
    2. Apply -> invoked with specific conetxt and arguments array.
    3. Bind -> Doesn't invoked immediately. just bind the specific context and then invoked later.
