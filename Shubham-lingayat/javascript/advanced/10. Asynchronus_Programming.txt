# Callback:
    - Callback is an method where function is passed as an argument to another Function.

------------------------------------------------------
# Callback Hell:
    - Callback Hell is a situation where multiple callabcks are added in nestead way.

    operation_01 (function(){
    ...
        operation_02(function(){
            ...
                operation_03(function(){... [..nestead way]})
        })
    })

    - Callback Hell also known as "pyramid of doom".
    - which leads to code become difficult to read, understand, and maintain.

------------------------------------------------------------------------
# Avoid CallBack Hell:
    - 1. Using Named Function 
            - Instead of passing Entire Function Code- only pass the next function name to be called.
    - 2. Using Promises:
            - after the First function is resolved then run next function.
    - 3. Async await:
            - wait for prev function to finish before stating cuurent/new function.
