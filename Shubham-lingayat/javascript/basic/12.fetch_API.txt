# Fetch API:
    - Fetch API always returns 'PROMISE' when we calling GET method .
    - Therefore we always use 'await' with fetch api.


    async function utility() {
    let content = await fetch('https://jsonplaceholder.typicode.com/posts/1');
    let output = await content.json();
    console.log(output);
    }

    utility();
