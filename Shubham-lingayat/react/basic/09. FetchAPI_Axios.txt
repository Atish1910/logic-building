# Fetch:
    - fetch is a built-in JavaScript function, so it doesn't require any additional libraries.
    - fetch returns Promises, making it easy to work with asynchrounus code using async/await syntax.
    
    1. GET - Fetch data:
        useEffect(()=>{
            fetch("https://api.example.com/users")
            .then(res => res.json())
            .then(data => setUsers(data))
            .catch(err => console.log(err));
        },[]);

    2. POST method - Create data

        const addUser = async() => {
            const response = await fetch("https://api.example.com/users",{
                method: "POST",
                headers: {
                    "Content-Type": "application/json"
                },
                body: JSON.stringify({
                    name: "shubham",
                    email: "shubham@gmail.com"
                })
            });

            const data = await response.json();

            console.log(data);
        }

    3. PUT method - Update data

        const UpdateUser = async() =>{
            const response = await fetch("https://api.example.com/users/1",{
                method: "PUT",
                headers: {
                    "Content-Type": "application/json"
                },
                body: JSON.stringify({
                    name: "shubham",
                    email: "shubham@gmail.com"
                })
            });

            const data = await response.json();
            console.log(data);
        }

    4. PATCH method - Update Specific fields

        const UpdateUser = async() => {
            const response = await fetch("https://api.example.com/users/1",{
                method: "PATCH",
                headers: {
                    "Content-Type": "application/json"
                },
                body: JSON.stringify({
                    name: "shubham"
                })
            });

            const data = await response.json();
            console.log(data);
        }

    5. DELETE method - Remove Data

        const deleteUser = async (id) =>{
            await fetch(`https://api.example.com/users/${id}`,{
                method: "DELETE"
            });
        };

    // GET
    fetch(url)

    //POST
    fetch( url, { method:"POST", headers, body })

    // PUT/ PATCH
    fetch( `${url}/1`, { method: "PUT", headers, body })

    // DELETE
    fetch( `${url}/1`, { method: "DELETE" })

--------------------------------------------------------------------------------
# PUT:
    - PUT replace the entire resource.
    - missing fields may be overwritten or removed.

# PATCH:
    - You send only the fields to change.
    - Other fields remain untouched

# axios:
    - It is third-party library
    - axios provides interceptors, which can be good for tasks like request/response logging,
        authentication, and error handling.
        import axios from 'axios';

    1. Axios GET method - Read data
        
        axios.get("https://api.example.com/users").
            then(response => {
                console.log(response.data);
            })
            .catch(error => {
                console.log(error);
            });


        ### OR ### --------------------------------
        
        const fetchData = async() =>{
            try{
                const response = await axios.get("https://api.example.com/users");
                console.log(response);                 <--- here we no need to use response.json();
            }
            catch(err){
                console.log(err);
            }
        }

        - We can use axios with then() - catch() OR async - await by adding try catch.

    2. Axios POST method - Add Data

        axios.post("https://api.example.com/users",{
            name: "Shubham",
            email: "shubham@gmail.com"
        }).then(res => console.log(res)) 
        .catch(err => console.log(err));

    3. Axios PUT method - Update Data

        axios.put("https://api.example.com/users/1",{
            name:"shubhbam",
            email: "shubham@gmail.com"
        }).then(res => console.log(res))
        .catch(err => console.log(err));

    4. Axios PATCH method - Update Specific data only

        axios.patch("https://api.example.com/users/1",{
            name:"Shubhzz"
        }).then(res => console.log(res))
        .catch(err => console.log(err));

    5. Axios DELETE method - Delete the data

        axios.delete("https://api.example.com/users/1");

# Difference between Axios and Fetch 

    Fetch :
        - Built-in method in React.
        - Must call response.json();  <--- convert to json.
        - Only rejects network error (no rejection on server status errors like 400, 404, 500 etc.)
        - No interceptores
        - default headers must set manually
    
    Axios :
        - third-party
        - Auto parse to JSON.
        - Rejects Promise for server status errors 400, 404, 500 etc.
        - contains interceptores
        - default headers are set automatically

# Axios:
    - Set Headers in Axios

        axios.get("https://api.example.com/users", {
            headers: {
                Authorization: "Bearer my-token",
                "X-Custom-Header": "myValue"
            }
        });

        ----- in POST method:
        
        axios.post("https://api.example.com/users",
            {
                name: "Shubham"
            },
            {
                headers: {
                Authorization: "Bearer my-token"
                }
            }
        );

    - Set global default headers:
        
        axios.defaults.headers.common["Authorization"] = "Bearer my-token";

# Interceptores in Axios:
    1. Request Interceptores:
        - Before request is send

            axios.interceptores.request.use(
                (config) =>{
                    const token = localStorage.getItem("token");

                    if (token){
                        config.headers.Authorization = `Bearer ${token}`;
                    }

                    return config;   // must return config
                },
                (error) => {
                    return Promise.reject(error);
                }
            );

        Syntax:
            axios.interceptores.request.use(res function , err function);

    2. Response interceptores:
        - Before a response is returned.

            axios.interceptores.response.use(
                (response) => {
                    return response;
                },
                (err) =>{
                    if (err.response && error.response.status === 401){
                        console.log("Unauthorized - redirect to Login");
                    }
                    return Promise.reject(err);
                }
            );
