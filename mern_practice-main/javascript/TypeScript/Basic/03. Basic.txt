# Access Modifiers in TypeScript classes:
    - in typescript we have Public, Private and Protected.
    - Protected is not officially supported in JS - it is exist in TypeScript.

    1. Public
    2. Private 
    3. Protected

    class Employee {
        public empId: number;
        private empName: string;
        protected empAge: number;
    }

    var objEmployee = new Employee();

    objEmployee.empId = 10;              // public is accessible
    objEmployee.empName = "Shuhbh";      // private is not accessible
    objEmployee.empAge = 22;      // protected is not accessible

    // -- Here Protected is accessible in Inherited Class from parent to Child --

    class PermanentEmployee extends Employee{
        empId = 100;
        empAge = 22;               // protected variable is accesscible
    }

    # Multiple Inheritance:
        - one derived class inherites from multiple Base class.
        - It is possible only through using "interface" and "implements".

        interface Employee{
            Salary()
        }

        interface User {
            Payroll()
        }

        class Admin implements Employee, User {
            Salary();         // Accessible
            Payroll();        // Accessible
        }

        - Using "extends" and "class" it is not possible for multiple Inheritance.

    1. Single Inheritance
    2. Multiple Inheritance   (using "interface" and "implements")
    3. MultiLevel Inheritance
    4. Hybrid Inheritance.  (using "interface" and "implements")

# Polymorphism:
    - Polymorphism means same name method can take multiple forms.

    function MyName(name){
        console.log(name);
    }

    function MyName(name, age){
        console.log(name);
    }

    MyName("shubh");            // Not works
    MyName("shubh", 22);        // Works

    - Here Second function will completely overries the previous one.

    1. Method Overloading
    2. Method Overiding

    1. Method Overloading:
        - Method Overloading means same method name but different parameters.
        - JavaScript doesn't support traditional method overloading.
        - If we define multiple methods with the same name, the last one overrides the previous one.
    
         - above example

    2. Method Overriding:
        - Happens in Inheritance, Parent class provides his method in Child class.
        - If child class contains same method as parent class then we have two option:
            1. Run the child method using child class.
            2. Run the parent method using "super" keyword.

        1. Example:
            class Animal {
                speak(){
                    console.log("Parent");
                }
            }

            class Dog extends Animal {
                speak(){
                    console.log("Child");
                }
            }

            const d = new Dog();
            d.speak();                        // Child

            --- Here Dog class overrides the Animal class's speak Method 

        2. Example:
            class Animal {
                speak(){
                    console.log("Parent");
                }
            }

            class Dog extends Animal {
                speak(){
                    super.speak();              // runs the parent method using "super" keyword
                    console.log("Child");
                }
            }

            const d = new Dog;
            d.speak();
            

            Output:
                Parent
                Child
            --- Here it runs both using super keyword. or we can change the method name in child class to be call the parent class.

# Abstraction:
    - Abstraction means hiding implementation details only showing the essentail features to user.

    function startCar() {
        ignition();
        injectFuel();
        startEngine();
    }

    function ignition() {
        console.log("Ignition started");
    }

    function injectFuel() {
        console.log("Fuel injected");
    }

    function startEngine() {
        console.log("Engine started");
    }

    startCar();

    --- Here startCar() is now abrstract method where all the internal code is hidden from user and user can see only the startCar() method.

# Extends Vs implements:

    1. extends:
        - A class inherites properties from Parent class using "extends"
        - one class can extend only one parent parent class.
        - Not able to apply Multiple Inheritance.

        - Using interface we can extend one class to Multiple Parent class.

        interface A {
            a():void;
        }
        interface B {
            a():void;
        }
        interface C extends A, B {
            a():void;
        }
    
        - extends can be used with "class" or "interface".
        - It inherites implementation/behaviour.
        - we can use "class" for single Inheritance and "interface" for multiple inheritance.
        - extends purpose is to Reuse the parent method code.

    2. implements:
        - implements can be used with "class" only.
        - It inherites type/contact only 
        - As we known interface is used to define the structure of object. -- here we can use interface to declare the structure of class (parent).
        - need to write code in child class id doesn't use code from parent class, 
          it just insure that all the methods comes from parent are need to be kept as it is.

            interface Animal {
                eat(): void;
            }

            interface Pet {
                play(): void;
            }

            class Dog implements Animal, Pet {
                eat() {
                    console.log("Dog eats");
                }
                play() {
                    console.log("Dog plays");
                }
            }

----------------------------------------------------------------------------------------
        interface Pet {
            play(): void;
        }

        class Animal {
            eat() {
                console.log("Animal eats");
            }
        }

        class Dog extends Animal implements Pet {
            play() {
                console.log("Dog plays");
            }
        }

        - Dog inherits eat() from Animal
        - Dog implements Pet contract
