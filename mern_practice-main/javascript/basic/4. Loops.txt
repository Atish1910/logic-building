# Loops:
    1. For Loop
    2. While Loop
    3. Do-While Loop
    4. For-in Loop
    5. For-of Loop

4. For-In Loop:
    - Works with Arrays, Objects

    object1 = {name:"Shubh", age:22}

    for (let i in object1){
        console.log(i); // will print key
        console.log(object1[i]); // will print Value
    }


5. For-Of Loop:
    - Doesn't work with Objects.         --------- IMP ************************* Error - Object is Not Iterable
    - Works with Arrays & String

    arr1 = [10,20,30,40,50]

    for (let i of arr1){
        console.log(i); // will print value
    }

    #------- String
    str1 = "Shubhamzz"

    for (let i of str1) {
        console.log(i); // will print value
    }
